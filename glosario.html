Glosario de Términos Clave en Automatización

Este glosario incluye los términos técnicos más importantes relacionados con los Autómatas Programables y los sistemas de control industrial.

Actuador
Dispositivo que convierte una señal eléctrica (salida del PLC) en una acción física, como movimiento, calor o luz. Ejemplos: motores, válvulas, luces piloto.
Autómata Programable (PLC)
Controlador Lógico Programable. Computadora industrial diseñada para controlar procesos secuenciales en tiempo real en entornos industriales exigentes.
Bus de Comunicación
Conjunto de líneas internas que permiten la transferencia de datos, direcciones e instrucciones entre la CPU, la memoria y los módulos de I/O de un PLC.
Ciclo de Scan
Proceso continuo y cíclico que realiza el PLC: 1) Leer Entradas, 2) Ejecutar el Programa, 3) Escribir Salidas, 4) Realizar tareas de autodiagnóstico/comunicación. El tiempo del ciclo se mide en milisegundos.
CPU (Central Processing Unit)
Unidad Central de Procesamiento. El "cerebro" del PLC que ejecuta el programa de control.
Diagrama de Escalera (Ladder Diagram - LD)
Uno de los lenguajes de programación del PLC (estándar IEC 61131-3). Es gráfico y simula la lógica de control cableada tradicional mediante contactos y bobinas.
Entradas/Salidas (I/O)
Abreviatura de Inputs/Outputs. Son las interfaces que conectan el PLC con los dispositivos de campo. Las entradas reciben señales; las salidas envían señales de control.
Grafcet (SFC - Sequential Function Chart)
Lenguaje de programación gráfico (estándar IEC 61131-3) basado en etapas y transiciones. Es ideal para procesos que siguen una secuencia clara.
HMI (Human-Machine Interface)
Interfaz Hombre-Máquina. Pantallas táctiles o paneles que permiten a los operadores interactuar con el PLC para monitorear y controlar el proceso.
LOTO (Lockout/Tagout)
Procedimiento de seguridad que consiste en bloquear y etiquetar las fuentes de energía de una máquina para evitar su activación accidental durante el mantenimiento.
Modularidad
Característica de los PLCs que permite ampliar el hardware (I/O, memoria, comunicación) mediante la adición de módulos en un *rack* o *backplane*.
Relé Programable
Controlador lógico compacto y de bajo coste, con I/O y memoria limitadas. Se utiliza para reemplazar relés, temporizadores y contadores en aplicaciones sencillas (ej. domótica).
Sensor
Dispositivo que detecta un evento físico (presencia, temperatura, presión) y lo convierte en una señal eléctrica para la entrada del PLC.
SCADA (Supervisory Control and Data Acquisition)
Sistema de software utilizado para la supervisión, control remoto y adquisición de datos en tiempo real de grandes instalaciones o procesos distribuidos.
